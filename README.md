## Featured projects

### [Adaptive Graph Engine](https://github.com/Hemanthf224/adaptive-graph-engine)

Graph analytics across CPU, GPU, and distributed execution, with Python bindings and an interactive dashboard.

- **Core work:** CSR graphs, traversal and ranking algorithms, CUDA kernels, and an MPI PageRank path.
- **Stack:** C++17 · CUDA · OpenMP · MPI · pybind11 · React · FastAPI.
- **Current focus:** portable builds, correctness checks, and reproducible benchmarks. Research extensions are experimental.

### [TaxiPulse](https://github.com/Hemanthf224/TaxiPulse_Bigdata)

A data engineering pipeline that turns NYC taxi trip files into cleaned, enriched, partitioned datasets for analysis and regression experiments.

- **Core work:** unify trip schemas, join weather and zone references, build features, and simulate Kafka streams.
- **Stack:** Scala · Apache Spark · HDFS · Kafka · Docker.
- **Current focus:** repeatable small-data runs, documented model evaluation, and portable setup.

### [SDN-OSHLD](https://github.com/Hemanthf224/SDN-OSHLD)

A network attack-classification prototype connecting model training, ensemble inference, policy recommendations, and a web dashboard.

- **Core work:** classifier training and inference through a FastAPI service with Flask visualizations.
- **Stack:** Python · scikit-learn · XGBoost · LightGBM · PyTorch · FastAPI.
- **Current focus:** independent evaluation and a reproducible training workflow. QoS responses currently use simulated values.
